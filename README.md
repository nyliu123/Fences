# Fences

当前版本：**1.7.15**。

Fences 是一款面向 Windows 桌面的分区整理工具，使用 C#、Windows Forms 和 .NET Framework 4.8 开发。它将常用文件、文件夹和快捷方式集中到可移动、可调整大小的桌面分区中，并提供外观设置、项目排序和系统托盘管理。

**本项目基于原作者 [Twometer](https://github.com/Twometer) 的开源项目 [NoFences](https://github.com/Twometer/NoFences) 进一步维护和完善，并以 Fences 作为本衍生版本的名称。** 原项目为本项目提供了基础实现；本版本在此基础上持续改进中文交互、分区外观、拖放体验、多屏定位、文件访问兼容性及退出恢复流程。感谢原作者的工作，原有版权声明和 MIT 许可证予以保留。

## 项目概况

Fences 以原生桌面窗口呈现分区，不需要打开独立的文件管理界面即可访问其中的项目。1.7.0 使用独立的 Windows 原生桌面视图，只隐藏属于分区的桌面图标，让其余图标自动补位。

**实际文件始终保留在加入分区时的原路径。** 分区只保存归属，不复制、移动或设置文件隐藏属性；其他软件的文件选择窗口可以直接访问这些路径。分区中的项目仍可打开、重命名、排序或取消归属；删除分区和退出程序会恢复图标显示，不会删除文件。版本变化见 [CHANGELOG.md](CHANGELOG.md)。

### 主要功能

| 功能 | 说明 |
| --- | --- |
| 桌面分区 | 新建、移动、缩放、锁定分区，支持自动收起和标题编辑；内容溢出时显示右侧滚动条，支持拖动、轨道翻页及滚轮。 |
| 项目整理 | 拖放导入文件、文件夹和快捷方式；分区内拖动排序，并提供菜单排序、“移回桌面”和“删除”操作。删除需确认，项目移入 Windows 回收站。 |
| 外观个性化 | 调整标题与项目字体、文字颜色、标题背景、分区背景透明度、窗口圆角、图标大小和间距；提供实时预览和批量设置。 |
| 输入保护 | 个性化滑块忽略垂直和水平滚轮，保留鼠标拖动及键盘调整，减少滚动页面时的误操作。 |
| 多屏定位 | 校正窗口与屏幕坐标，在启动、显示器布局变化及移动结束时将越界分区调整到可用区域内。 |
| 文件窗口兼容 | 文件保留原路径，文件选择窗口直接可用，无须等待调用软件退出后再收回。 |
| 原生桌面视图 | 分区成员只从桌面视图中过滤；支持原生查看、排序、刷新、新建和经典 Shell 菜单。 |
| 系统集成 | 系统托盘管理、文件扩展名显示、图像缩略图，以及适用程序和快捷方式的“以管理员身份运行”。有效快捷方式还可“打开文件所在位置”或“打开文件夹所在位置”，在资源管理器中选中实际目标。 |
| 恢复与诊断 | 接管图标层前保存恢复记录，配备退出恢复程序与异常日志；接管失败时保留原桌面可用。 |

### 相对原项目的完善方向

- 提供中文菜单、个性化设置、实时外观预览及批量操作。
- 协调分区主体、标题、图标与编辑窗口的绘制和交互。
- 改善拖放失败回退、项目排序、跨屏定位和字体资源生命周期。
- 将文件整理改为原路径归属与视图过滤，文件选择和网页上传不再依赖临时移动文件。
- 删除分区或退出程序时，先关闭分区及附属窗口，再恢复桌面项目；删除失败时重新打开保留剩余项目的分区。
- 增加覆盖拖放、外观、窗口定位、文件访问和退出顺序的回归检查。

## 运行与使用

### 运行环境

- 64 位 Windows 10／Windows 11。
- .NET Framework 4.8 或兼容的更新版本。

### 安装与启动

1. 准备完整发布包，或按下方步骤编译项目。
2. 将程序文件和语言资源子目录一起解压到可读写目录，例如 `D:\Fences`；原有的 `D:\NoFences` 目录也可以继续使用。
3. 运行 `Fences.exe`。请同时保留 `Fences.Desktop.dll`、`Fences.Recovery.exe`、两个程序的 `.config` 文件以及语言资源子目录。
4. 从系统托盘菜单新建分区，将桌面项目拖入分区；右键分区空白区域可调整该分区的设置，托盘菜单提供批量设置。

更新前请先从托盘菜单退出旧版，待恢复流程结束后再替换文件。从 NoFences 升级后，入口名称变为 **`Fences.exe`**，原有快捷方式或开机启动项需要更新到新入口。

使用自解压发行包时，运行 `Fences-<版本>-win-x64-sfx.exe`，同意管理员权限确认后选择目录并解压。默认目录为 `C:\Program Files\Fences`，也可改为其他位置；解压后运行其中的 `Fences.exe`，主程序仍使用普通用户权限。包内只包含发行文件和默认运行配置，个人分区配置、项目和日志不会随包分发。自解压包的构建方法见 [Packaging/README.md](Packaging/README.md)。

### 文件与数据的生命周期

- **拖入分区：** 保存原路径归属并隐藏对应桌面图标，实际文件保持原位。外部源须支持引用（Link）拖放；仅允许复制或移动的来源会被拒绝，防止源程序清理尚未保留的临时文件。
- **文件选择：** 直接读取真实路径；打开或关闭文件选择窗口、调用软件退出，都不会移动文件。
- **手动刷新：** 托盘“刷新”重新同步分区归属、桌面视图和分区显示；视图失败后可手动重试。
- **移回桌面／删除分区：** 取消对应归属并恢复图标；真实文件不变。菜单“删除”仍会在确认后移入 Windows 回收站。
- **退出 Fences：** 先关闭分区及附属窗口，再还原 Explorer 图标层；文件继续留在真实目录。恢复程序使用会话记录处理主程序异常终止。

“显示桌面图标”、自动排列、图标大小、排序及手动位置保存为 Fences 的桌面视图设置；退出时恢复启动前原生图标层的可见状态。当前提供经典 Shell 菜单，不复刻 Windows 11 新版首层菜单。动态壁纸、全部第三方 Shell 扩展及物理混合 DPI 多屏仍需在对应环境中确认。

### 数据位置与旧版兼容

分区归属、桌面视图设置与日志使用：

```text
%LocalAppData%\Fences\
├─ <分区 ID>\                  __fence_metadata.xml（原路径与外观等）
├─ desktop-view-settings.xml    桌面显示设置与手动位置
├─ desktop-view-session.xml     运行期间的图标层恢复记录
└─ Logs\                       异常日志
```

首次启动时，程序会检测旧的 `%LocalAppData%\NoFences` 目录，迁移配置、项目和日志，并修正旧存储路径。升级 1.7 时，旧版存储项目通过恢复日志迁回桌面，同名项目保留双方，随后保存实际路径；个性化和分区位置保留，旧的临时调用进程记录不再使用。中断后可继续恢复；新旧目录有同名分区时不会覆盖。旧版未记录的完整外部来源路径无法推断，升级前建议备份。

更换程序安装目录不影响数据位置。实际文件仍在桌面或其他原始目录，备份时需同时备份真实文件及整个 `%LocalAppData%\Fences`；建议先退出程序。旧名称的单实例和恢复互斥机制继续用于与旧版协调，确保迁移在旧恢复进程完成后执行。异常日志位于 `%LocalAppData%\Fences\Logs`。

## 从源码编译

安装 Visual Studio 或 Visual Studio Build Tools，包含 .NET Framework 4.8 目标框架、C++ x64 Build Tools 和 Windows SDK。在开发者命令行中运行：

```powershell
msbuild Fences.sln /t:Build /p:Configuration=Release /v:minimal /nologo
```

主要输出位于 `Fences\bin\Release\`：

```text
Fences.exe
Fences.exe.config
Fences.Desktop.dll
Fences.Recovery.exe
Fences.Recovery.exe.config
cs\Fences.resources.dll
zh-CN\Fences.resources.dll
```

分发时请附带本项目的 `LICENSE` 和来源说明。`Fences.pdb` 可用于辅助定位异常。

仓库与源码目录均使用 `Fences`，解决方案入口为 `Fences.sln`，源码项目位于 `Fences/Fences.csproj`。内部仍保留 `NoFences` 命名空间，以兼容既有资源与反射引用；这不影响目录名、应用名称或构建输出。

## 开发与验证

- `Fences.sln`：解决方案入口。
- `Fences/Fences.csproj`：Windows Forms 应用与恢复程序的构建入口。
- `Fences.Native/`：C++17 原生桌面视图、原路径过滤与经典菜单桥接，由构建入口自动编译。
- `Fences/Model/`：分区信息、原路径归属、桌面显示设置及持久化。
- `Fences/Win32/`：桌面宿主、文件窗口监听及 Windows 原生接口。
- `Fences/Util/`：缩略图、恢复、文件访问协调和窗口关闭流程。
- `Tests/`：Windows 回归测试，执行方法见 [测试说明](Tests/README.md)。
- [DESIGN.md](DESIGN.md)：现有界面风格与交互约定。

自动化检查覆盖旧版回归，以及原路径导入、迁移冲突、保存失败回退、外部改名和删除、原生菜单、现代文件选择、视图设置重载、退出顺序与跨进程异常终止恢复。历史临时移动模式的测试继续用于兼容性检查。真实 Explorer 重启、不同系统主题、物理混合缩放多屏与全部 Shell 扩展仍需对应环境验证。
