# Fences

Fences 是一款面向 Windows 桌面的分区整理工具，使用 C#、Windows Forms 和 .NET Framework 4.8 开发。它将常用文件、文件夹和快捷方式集中到可移动、可调整大小的桌面分区中，并提供外观设置、项目排序和系统托盘管理。

**本项目基于原作者 [Twometer](https://github.com/Twometer) 的开源项目 [NoFences](https://github.com/Twometer/NoFences) 进一步维护和完善，并以 Fences 作为本衍生版本的名称。** 原项目为本项目提供了基础实现；本版本在此基础上持续改进中文交互、分区外观、拖放体验、多屏定位、文件访问兼容性及退出恢复流程。感谢原作者的工作，原有版权声明和 MIT 许可证予以保留。

## 项目概况

Fences 以原生桌面窗口呈现分区，不需要打开独立的文件管理界面即可访问其中的项目。分区信息和项目归属保存在本地，程序正常退出时会将项目移回桌面，下次启动时再按保存的归属整理到对应分区。

拖入分区会**移动实际文件或文件夹**，而不是复制一份或仅隐藏桌面图标。分区中的项目仍可直接打开、重命名、排序或移回桌面；删除分区只移除分区本身，其中的项目会恢复到桌面。

### 主要功能

| 功能 | 说明 |
| --- | --- |
| 桌面分区 | 新建、移动、缩放、锁定分区，支持自动收起和标题编辑。 |
| 项目整理 | 拖放导入文件、文件夹和快捷方式；分区内拖动排序，并提供菜单排序操作。 |
| 外观个性化 | 调整标题与项目字体、文字颜色、标题背景、分区背景透明度、窗口圆角、图标大小和间距；提供实时预览和批量设置。 |
| 输入保护 | 个性化滑块忽略垂直和水平滚轮，保留鼠标拖动及键盘调整，减少滚动页面时的误操作。 |
| 多屏定位 | 校正窗口与屏幕坐标，在启动、显示器布局变化及移动结束时将越界分区调整到可用区域内。 |
| 文件窗口兼容 | 检测标准 Windows 打开／保存文件窗口，临时将分区项目恢复到桌面；等待相关调用进程全部退出后再收回。 |
| 系统集成 | 系统托盘管理、文件扩展名显示、图像缩略图，以及适用程序和快捷方式的“以管理员身份运行”。 |
| 恢复与诊断 | 保存分区归属与临时恢复状态，配备退出恢复程序和异常日志；移动失败时保留项目所在路径并报告错误。 |

### 相对原项目的完善方向

- 提供中文菜单、个性化设置、实时外观预览及批量操作。
- 协调分区主体、标题、图标与编辑窗口的绘制和交互。
- 改善拖放失败回退、项目排序、跨屏定位和字体资源生命周期。
- 为软件或网页调用的原生文件选择窗口恢复桌面项目，并保存调用进程的身份与生命周期状态。
- 删除分区或退出程序时，先关闭分区及附属窗口，再恢复桌面项目；删除失败时重新打开保留剩余项目的分区。
- 增加覆盖拖放、外观、窗口定位、文件访问和退出顺序的回归检查。

## 运行与使用

### 运行环境

- 64 位 Windows 10／Windows 11。
- .NET Framework 4.8 或兼容的更新版本。

### 安装与启动

1. 准备完整发布包，或按下方步骤编译项目。
2. 将程序文件和语言资源子目录一起解压到可读写目录，例如 `D:\Fences`；原有的 `D:\NoFences` 目录也可以继续使用。
3. 运行 `Fences.exe`。请同时保留 `Fences.Recovery.exe`、两个程序的 `.config` 文件以及语言资源子目录。
4. 从系统托盘菜单新建分区，将桌面项目拖入分区；右键分区空白区域可调整该分区的设置，托盘菜单提供批量设置。

更新前请先从托盘菜单退出旧版，待恢复流程结束后再替换文件。从 NoFences 升级后，入口名称变为 **`Fences.exe`**，原有快捷方式或开机启动项需要更新到新入口。

使用自解压发行包时，运行 `Fences-<版本>-win-x64-sfx.exe`，选择目标目录并解压，再运行其中的 `Fences.exe`。包内只包含发行文件和默认运行配置，个人分区配置、项目和日志不会随包分发。自解压包的构建方法见 [Packaging/README.md](Packaging/README.md)。

### 文件与数据的生命周期

- **拖入分区：** 实际项目移动到分区存储目录，桌面上的源项目随之移除。
- **文件选择：** 其他软件打开标准 Windows 文件选择窗口后，分区项目临时回到桌面。关闭选择窗口不会立即收回，以便调用软件继续读取所选路径。
- **调用软件退出：** 相关调用进程全部退出后，临时恢复的项目自动收回分区；多个软件同时使用时会等待它们全部退出。
- **移回桌面／删除分区：** 相应项目回到桌面，删除分区不会删除其中的文件。
- **退出 Fences：** 先关闭所有分区窗口，再恢复桌面项目；恢复程序用于在主程序退出后继续处理已保存的恢复信息。

若项目被占用、权限不足或移动失败，程序会保留其当前路径并提示错误。自定义文件浏览界面若未使用标准 Windows Shell 文件选择窗口，不在自动检测范围内。浏览器等软件若仍有对应后台进程运行，项目会继续保留在桌面。

### 数据位置与旧版兼容

配置、分区项目和日志统一使用：

```text
%LocalAppData%\Fences\
├─ <分区 ID>\                  分区项目与 __fence_metadata.xml
└─ Logs\                       异常日志
```

首次启动时，程序会检测旧的 `%LocalAppData%\NoFences` 目录，迁移其中的配置、项目和日志，并修正配置中指向旧存储位置的绝对路径。桌面及其他外部文件路径保持不变，个性化设置和临时桌面访问状态也会保留。迁移中断后可在下次启动时继续；新旧目录若存在同名分区，会报告冲突并保留双方数据，不会覆盖配置。

更换程序安装目录不影响数据位置。备份时应包含整个 `%LocalAppData%\Fences` 目录；建议先正常退出程序，避免在文件移动过程中复制数据。旧名称的单实例和恢复互斥机制仅用于与旧版协调，确保迁移在旧恢复进程完成后执行。正常运行和退出恢复都读写新目录，异常日志位于 `%LocalAppData%\Fences\Logs`。

## 从源码编译

安装 Visual Studio 或 Visual Studio Build Tools，并包含 .NET 桌面开发工具及 .NET Framework 4.8 目标框架支持。在开发者命令行中运行：

```powershell
msbuild Fences.sln /t:Build /p:Configuration=Release /v:minimal /nologo
```

主要输出位于 `Fences\bin\Release\`：

```text
Fences.exe
Fences.exe.config
Fences.Recovery.exe
Fences.Recovery.exe.config
cs\Fences.resources.dll
zh-CN\Fences.resources.dll
```

分发时请附带本项目的 `LICENSE` 和来源说明。`Fences.pdb` 可用于辅助定位异常。

仓库与源码目录均使用 `Fences`，解决方案入口为 `Fences.sln`，源码项目位于 `Fences/Fences.csproj`。内部仍保留 `NoFences` 命名空间，以兼容既有资源与反射引用；这不影响目录名、应用名称或构建输出。

## 开发与验证

- `Fences.sln`：解决方案入口。
- `Fences/Fences.csproj`：Windows Forms 应用与恢复程序的构建入口。
- `Fences/Model/`：分区信息、文件归属、持久化和临时桌面访问状态。
- `Fences/Win32/`：桌面宿主、文件窗口监听及 Windows 原生接口。
- `Fences/Util/`：缩略图、恢复、文件访问协调和窗口关闭流程。
- `Tests/`：Windows 回归测试，执行方法见 [测试说明](Tests/README.md)。
- [DESIGN.md](DESIGN.md)：现有界面风格与交互约定。

自动化检查覆盖拖放失败回退、滑块滚轮保护、圆角与布局、分区定位、文件窗口识别、多进程临时恢复、重启兼容及窗口关闭顺序。真实 Explorer 拖放表现、不同系统主题和物理混合缩放多屏仍建议进行实际桌面验证。
